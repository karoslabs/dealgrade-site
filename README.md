# Dealgrade site: design preview

A review copy of a redesign of dealgrade.co, made by Karos Labs for the Dealgrade team.
It is not Dealgrade's live site. Every page says so at the top, and nothing typed into it is sent anywhere.

Preview: https://karoslabs.github.io/dealgrade-site/

Plain HTML, CSS and JavaScript, with no build step. The numbers come from the public pages of dealgrade.co
(sales data to 7 July 2026, project details as read on 10 November 2026).
